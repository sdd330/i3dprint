## 目录

- [apps/web](apps/web)：Nuxt SSR
- [db/e3dp_schema.sql](db/e3dp_schema.sql)：建表脚本，库名 `i3dprint`
- [docs/数据库设计.md](docs/数据库设计.md)：技术栈、命名、类型与表说明
